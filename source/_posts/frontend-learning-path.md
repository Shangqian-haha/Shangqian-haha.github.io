写博客难免要跟前端打交道，索性系统地学了一遍。这里整理一条我走过的路线，供参考。

## 第一阶段：基础三件套

- **HTML**：语义化标签、表单
- **CSS**：盒模型、Flex/Grid 布局、响应式
- **JavaScript**：语法、DOM、事件、异步

这个阶段最重要的产出，是能独立写一个静态页面。

## 第二阶段：工程化

```bash
# 现代前端项目几乎都从脚手架开始
npm create vite@latest
```

理解模块化、打包工具（Vite/Webpack）、包管理，是进入工程化的门槛。

## 第三阶段：框架

| 框架 | 特点 |
| --- | --- |
| Vue | 上手平缓，中文生态好 |
| React | 社区庞大，就业面广 |

个人建议先精通一个，再横向扩展，切忌贪多嚼不烂。

## 写在最后

前端技术更新极快，但底层原理（浏览器、网络、渲染）是稳定的。把基础打牢，才能以不变应万变。
