作为大数据专业的学生，Python 是绕不开的工具。而 Pandas，是 Python 做数据分析时第一个绕不过去的坎——Excel 里点点鼠标就能干的事，到 Pandas 里全变成一行行代码，一开始真有点挫败感。

后来发现，其实常用的就那么几个操作，翻来覆去地用。这篇把它们整理成一份”能随时回来抄”的备忘录。

下面这套代码用的是一组学生数据（张三、李四、王五这几位老熟人），跟着敲一遍，比看十遍文档都管用。

一句话定位：Series 是一列，DataFrame 是一张表，loc[] 是查数据的钥匙，groupby() 是分析的发动机。把这几样吃透，80% 的日常数据活儿就够用了。

Pandas 的操作看着多，其实就围着四件事转：造数据、查数据、洗数据、算数据。把这四类各记熟一两个方法，日常活儿基本就够用了。

最后附一张速查表，忘了就回来抄：

想干啥 用哪个 记忆点
造表 pd.DataFrame() 字典列表最像真实数据
查值 / 查行 / 查列 df.loc[行, 列] 行在前，列在后
条件筛选 df.loc[(条件) & (条件)] 每个条件都要带括号
删行删列 df.drop(..., axis=0/1) axis=0 行，axis=1 列
补空值 fillna() / dropna() 填还是删，看业务
去重 drop_duplicates() keep 控制保留哪条
批量转换 apply() / map() apply 套函数，map 查字典
分组统计 groupby() + agg() 分析的主力
表连接 merge() / concat() merge 左右拼列，concat 上下拼行

一句话总结：工具只是手段，理解数据背后的业务含义才是关键——别为了炫技把冷冰冰的代码当成目的。

三个实用建议：

  1. 先跑通造数据这步：没有数据什么都练不了，DataFrame 建表是第一步
  2. loc[] 要练到肌肉记忆：行在前列在后，这个顺序搞反了会一直报错
  3. groupby 是分水岭：会用 groupby，才算从”操作表格”迈进”分析数据”
